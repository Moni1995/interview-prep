1. Foundations

Experiment, sample space, events, axioms

  • Experiment — a procedure with an uncertain result (toss a coin, roll two dice, will it rain tomorrow).
  • Outcome — one result of a single trial.
  • Sample space \( \Omega \) (or \(S\)) — the set of all outcomes. Die: \( \Omega=\{1,2,3,4,5,6\} \). Two dice: 36 ordered pairs.
  • Event — any subset of \( \Omega \). "Even number" \( = \{2,4,6\} \).
  • Probability — a function \(P\) assigning a number to each event, obeying the three axioms.
Kolmogorov axioms \[ 0 \le P(A) \le 1, \qquad P(\Omega)=1, \qquad P\Big(\bigcup_i A_i\Big)=\sum_i P(A_i)\ \text{ for pairwise disjoint } A_i . \] Consequences: \(P(\varnothing)=0\); \(P(A^c)=1-P(A)\); if \(A\subseteq B\) then \(P(A)\le P(B)\).

For equally likely outcomes (classical definition): \[ P(A)=\frac{\#\text{ favourable outcomes}}{\#\text{ total outcomes}} . \]

Example — sum of two dice Each of the 36 ordered pairs has probability \(1/36\). Number of pairs giving each sum:

So \(P(\text{sum}=8)=5/36\approx 0.139\) and \(P(\text{sum}\ne 8)=31/36\).
Trap A number like \(-0.00001\) or \(1.001\) can never be a probability (axiom 1). A probability of exactly 0 or exactly 1 is allowed.
Apply it — quality control A batch holds 20 items, 4 of them defective. An inspector draws 2 at random. What is the probability of catching at least one defective?
Show the step-by-step solution
1 — Choose the sample space (classical rule). All \(\binom{20}{2}=190\) pairs are equally likely.
2 — Go through the complement ("at least one" trap): the complement is "both fine": \(\binom{16}{2}=120\) pairs.
3 — Apply \(P(A)=1-P(A^c)\): \(P=1-\dfrac{120}{190}=\dfrac{70}{190}=\dfrac{7}{19}\approx0.368\).
Sanity check: drawing 2 of 20 with 20 % defective — a bit more than a third catching one feels right; with replacement it would be \(1-0.8^2=0.36\), very close.

Example — can two events be disjoint? If \(P(A)=0.6\) and \(P(B)=0.7\) and they were disjoint, \(P(A\cup B)=1.3>1\): impossible. In fact \(P(A\cap B)\ge P(A)+P(B)-1=0.3\).
Example — decomposing a union into disjoint pieces Any union can be sliced into non-overlapping parts. Take \(C\) whole, then the part of \(A\) outside \(C\), then the part of \(B\) outside both: \[ P(A\cup B\cup C)=P(C)+P(A\cap C^c)+P(B\cap A^c\cap C^c). \] Draw the Venn diagram and check that each region is counted exactly once. Partitioning like this is the standard way to avoid double counting.

De Morgan: \((A\cup B)^c=A^c\cap B^c\) and \((A\cap B)^c=A^c\cup B^c\). Useful for "at least one" questions: \(P(\text{at least one})=1-P(\text{none})\).

Apply it — tool-usage survey In a team, 60 % use Python, 40 % use R, and 25 % use both. Find: (a) P(uses Python or R), (b) P(uses neither), (c) P(uses exactly one).
Show the step-by-step solution
1 — Inclusion–exclusion: \(P(Py\cup R)=0.6+0.4-0.25=0.75\).
2 — Complement: \(P(\text{neither})=1-0.75=0.25\).
3 — Disjoint decomposition: exactly one \(=P(Py\cup R)-P(\text{both})=0.75-0.25=0.50\) (or \((0.6-0.25)+(0.4-0.25)\)).
Bonus: are Python and R use independent? \(P(Py)P(R)=0.24\ne0.25\) — almost, but not quite.

2. Counting

Core formulas
  • Multiplication rule: \(k\) independent choices with \(n_1,\dots,n_k\) options give \(n_1 n_2\cdots n_k\) outcomes.
  • Permutations (order matters): \(\;{}^nP_r=\dfrac{n!}{(n-r)!}\)
  • Combinations (order irrelevant): \(\;\dbinom{n}{r}={}^nC_r=\dfrac{n!}{r!\,(n-r)!}\)
  • With repetition allowed, \(r\) picks from \(n\) symbols: \(n^r\).
Example — all six rolls distinct Roll a die 6 times. Favourable sequences: \(6!\) (a permutation of 1–6). Total: \(6^6\). \[ P=\frac{6!}{6^6}=\frac{720}{46656}\approx 0.0154 . \]
Example — the birthday problem \(n\) people, 365 equally likely birthdays. \(P(\text{all different})=\dfrac{365}{365}\cdot\dfrac{364}{365}\cdots\dfrac{365-n+1}{365}\). For \(n=23\) this is ≈ 0.493, so \(P(\text{some shared})\approx 0.507\); for \(n=30\), \(P(\text{shared})\approx 0.706\). Memorise: 23 → 50 %, 30 → 70 %, 50 → 97 %.
Example — same class 60 students split into 3 equal classes of 20. Put Jack anywhere; of the remaining 59 seats, 19 are in Jack's class, so \(P(\text{Jill with Jack})=19/59\approx 0.322\). (Not \(1/3\): the seats are finite, like sampling without replacement.)
Example — subset of a hand Four specific cards are marked (then returned). Someone draws 8 from 52. Probability all 4 marked cards are among the 8: choose the 4 marked (1 way) and 4 more from the other 48: \[ P=\frac{\binom{48}{4}}{\binom{52}{8}} . \]
Example — symmetry beats counting Deal 13 cards; what is \(P(13\text{th card is a King})\)? By symmetry every position is equally likely to hold any card, so the answer is the same as for the first card: \(4/52=1/13\).
Example — ordered comparison Roll a 4-sided die twice. 16 equally likely pairs; 4 are ties, the remaining 12 split evenly, so \(P(\text{first} > \text{second})=6/16=3/8\).
Example — geometric probability A coin of diameter 1 lands on a grid of lines 2 apart. The centre must stay ≥ 0.5 from every line, i.e. inside a 1×1 square within each 2×2 cell: \(P=1/4\). When outcomes are continuous, probability = favourable area / total area.
Apply it — a five-card hand From a standard 52-card deck you are dealt 5 cards. Probability of exactly 2 aces?
Show the step-by-step solution
1 — Count total hands (combinations, order irrelevant): \(\binom{52}{5}=2\,598\,960\).
2 — Build the favourable hands with the multiplication rule: choose 2 of the 4 aces, \(\binom42=6\); choose the other 3 cards from the 48 non-aces, \(\binom{48}{3}=17\,296\).
3 — Divide: \(P=\dfrac{6\times17\,296}{2\,598\,960}=\dfrac{103\,776}{2\,598\,960}\approx0.0399\).
Rule check: the numerator must classify every card of the hand (2 aces AND 3 non-aces) — forgetting the \(\binom{48}{3}\) factor is the classic error.

3. Conditional probability

Definition \[ P(A\mid B)=\frac{P(A\cap B)}{P(B)}, \qquad P(B)>0 . \] "Probability of A given B": restrict the sample space to \(B\) and renormalise.
Example — cards \(P(\text{King}\mid\text{face card})=\dfrac{4}{12}=\dfrac13\) (12 face cards: J, Q, K of 4 suits).
Example — contingency table

Example — two tests 25 % passed both tests, 45 % passed the first. \(P(\text{2nd}\mid\text{1st})=\dfrac{0.25}{0.45}=0.556\approx 55\%\).
Example — the two-child problem A family has two children, at least one a girl. Sample space (older, younger): GG, GB, BG, BB. Conditioning removes BB, leaving 3 equally likely cases; only GG has two girls, so \(P=1/3\), not \(1/2\). (If instead you were told "the older child is a girl", the answer is \(1/2\).)
Apply it — spam filtering by hand 30 % of incoming email is spam. The word "free" appears in 40 % of spam. Overall, 16 % of all email contains "free". An email contains "free" — probability it is spam?
Show the step-by-step solution
1 — Get the joint with the chain rule: \(P(\text{spam}\cap\text{free})=P(\text{spam})\,P(\text{free}\mid\text{spam})=0.3\times0.4=0.12\).
2 — Apply the conditional-probability definition: \(P(\text{spam}\mid\text{free})=\dfrac{P(\text{spam}\cap\text{free})}{P(\text{free})}=\dfrac{0.12}{0.16}=0.75\).
3 — Read the direction: we flipped from \(P(\text{free}\mid\text{spam})=0.4\) to \(P(\text{spam}\mid\text{free})=0.75\) — they are different questions with different answers.

Chain (multiplication) rule

\[ P(A\cap B)=P(A)\,P(B\mid A)=P(B)\,P(A\mid B) \] \[ P(A_1\cap A_2\cap A_3)=P(A_1)\,P(A_2\mid A_1)\,P(A_3\mid A_1\cap A_2) \] In particular \(P(A\cap B\cap C^c)=P(A)\,P(C^c\mid A)\,P(B\mid A\cap C^c)\) — an identity that holds for any events (with positive-probability conditions).
Example — without replacement 3 black and 3 white marbles; draw two without replacement. \(P(\text{both black})=\dfrac36\cdot\dfrac25=\dfrac15\).
Apply it — urn, three draws An urn holds 5 red and 3 blue marbles. Draw 3 without replacement. Find (a) P(red, red, blue in that order), (b) P(all three the same colour).
Show the step-by-step solution
1 — Chain rule, updating the urn each draw: \(P(RRB)=\dfrac58\cdot\dfrac47\cdot\dfrac36=\dfrac{60}{336}=\dfrac{5}{28}\approx0.179\).
2 — For (b), split into disjoint cases: \(P(RRR)=\dfrac{5\cdot4\cdot3}{8\cdot7\cdot6}=\dfrac{60}{336}\), \(P(BBB)=\dfrac{3\cdot2\cdot1}{336}=\dfrac{6}{336}\).
3 — Add (disjoint events): \(\dfrac{66}{336}=\dfrac{11}{56}\approx0.196\).
Rule check: each factor conditions on everything drawn so far — that is \(P(A_1)P(A_2\mid A_1)P(A_3\mid A_1\cap A_2)\) in action.

Independence

\(A\) and \(B\) are independent iff \[ P(A\cap B)=P(A)\,P(B) \iff P(A\mid B)=P(A). \] Independence is not the same as disjointness: disjoint events with positive probability are maximally dependent (if one happens the other cannot).
Examples
  • Red marble (4 red, 3 black) and heads: \(\frac47\cdot\frac12=\frac27\).
  • Die twice, "2 then not 4": \(\frac16\cdot\frac56=\frac5{36}\).
  • 3 red + 1 white marble, two draws with replacement, same colour: \((\tfrac34)^2+(\tfrac14)^2=\tfrac{10}{16}=\tfrac58\).
  • Bagel 60 %, pizza 50 %, \(P(\text{bagel}\mid\text{pizza})=0.7\ne0.6\) ⇒ dependent.
Example — an event independent of itself Need \(P(A\cap A)=P(A)^2\), i.e. \(P(A)=P(A)^2\), which holds only for \(P(A)=0\) or \(P(A)=1\).
Trap — gambler's fallacy After three tails, a fair coin is still 50/50 on the next toss. Independent trials have no memory. Past losses do not make heads "due".
Apply it — system reliability Two independent servers are up 95 % and 90 % of the time. Find (a) P(both up) — a "series" system, (b) P(at least one up) — a "parallel" system.
Show the step-by-step solution
1 — Independence product rule: \(P(\text{both})=0.95\times0.90=0.855\).
2 — Parallel via the complement: \(P(\text{at least one})=1-P(\text{both down})=1-0.05\times0.10=0.995\).
3 — Where independence enters: both steps multiplied probabilities — legal only because the servers fail independently. If they share a power supply, \(P(\text{both down})>0.005\) and the parallel system is worse than computed. Always ask "is independence justified?" before multiplying.

Law of total probability

If \(B_1,\dots,B_n\) partition \(\Omega\) (disjoint, exhaustive): \[ P(A)=\sum_i P(A\mid B_i)\,P(B_i) . \] Two-case version: \(P(A)=P(A\mid B)P(B)+P(A\mid B^c)P(B^c)\).
Example — mixed coins, expected tosses Coin A (\(p=\tfrac12\)) chosen with prob \(\tfrac14\); coin B (\(p=\tfrac13\)) with prob \(\tfrac34\). Toss until the first head. For a geometric variable \(E[\text{tosses}]=1/p\), so \[ E[T]=\tfrac14\cdot 2+\tfrac34\cdot 3=2.75 . \]
Apply it — traffic split between two models 70 % of requests go to model A (error rate 2 %), 30 % to model B (error rate 6 %). (a) Overall error rate? (b) An error occurred — probability it came from A?
Show the step-by-step solution
1 — Law of total probability over the partition {A, B}: \(P(E)=0.7\times0.02+0.3\times0.06=0.014+0.018=0.032\).
2 — For (b), definition of conditional probability: \(P(A\mid E)=\dfrac{0.014}{0.032}=0.4375\).
3 — Interpret: A handles 70 % of traffic but causes only ~44 % of the errors; B causes 56 % from just 30 % of traffic. This two-step (total probability, then divide) is Bayes' theorem — next section.

4. Bayes' theorem

\[ P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}=\frac{P(B\mid A)\,P(A)}{P(B\mid A)P(A)+P(B\mid A^c)P(A^c)} \]
\(P(A)\)prior — belief before seeing the evidence
\(P(B\mid A)\)likelihood — how probable the evidence is if \(A\) is true
\(P(B)\)evidence / marginal — total probability of the evidence (from the law of total probability)
\(P(A\mid B)\)posterior — updated belief
Bayes "reverses" a conditional: it turns \(P(\text{evidence}\mid\text{cause})\) into \(P(\text{cause}\mid\text{evidence})\).

Recipe that never fails: (1) write down the prior of each hypothesis; (2) write the likelihood of the observed evidence under each hypothesis; (3) multiply; (4) divide by the sum. Or think in natural frequencies: imagine 100 000 people and count.

Medical-test examples

Example — ELISA / cancer screening Prior (prevalence) \(=0.00148\); sensitivity (true-positive rate) \(=0.93\); specificity (true-negative rate) \(=0.99\) ⇒ false-positive rate \(=0.01\). \[ P(D\mid +)=\frac{0.93\times0.00148}{0.93\times0.00148+0.01\times0.99852}=\frac{0.001376}{0.001376+0.009985}\approx0.121 . \] Only ~12 % of positives are truly sick, because the disease is rare and false positives from the huge healthy group swamp the true positives.
Frequency view: of 100 000 people, 148 are sick → 138 test positive; 99 852 are healthy → 999 test positive. 138 / (138 + 999) ≈ 12 %.
Example — typhoid Prevalence 1 %, sensitivity 80 %, false-positive rate 10 %. \[ P(T\mid+)=\frac{0.8\times0.01}{0.8\times0.01+0.1\times0.99}=\frac{0.008}{0.107}\approx 0.075\approx 7\% . \]
Example — second interview \(P(\text{call})=0.5\); \(P(\text{felt good}\mid\text{call})=0.95\); \(P(\text{felt good}\mid\text{no call})=0.75\). \[ P(\text{call}\mid\text{felt good})=\frac{0.95\times0.5}{0.95\times0.5+0.75\times0.5}=\frac{0.475}{0.85}\approx0.56 . \]
Example — identical twins \(P(I)=0.3\), \(P(F)=0.7\); \(P(GG\mid I)=0.5\), \(P(GG\mid F)=0.25\). \[ P(I\mid GG)=\frac{0.3\times0.5}{0.3\times0.5+0.7\times0.25}=\frac{0.15}{0.325}\approx0.46 . \]
Example — two-tailed coin Real coin or double-tails coin, chosen 50/50; the toss shows tails. \[ P(\text{faulty}\mid T)=\frac{1\times\frac12}{1\times\frac12+\frac12\times\frac12}=\frac{1/2}{3/4}=\frac23 . \]
Apply it — fraud flagging 0.5 % of transactions are fraudulent. A model flags 95 % of fraud but also 3 % of legitimate transactions. A transaction is flagged — probability it is fraud?
Show the step-by-step solution
1 — Name the pieces: prior \(P(F)=0.005\); likelihoods \(P(\text{flag}\mid F)=0.95\), \(P(\text{flag}\mid F^c)=0.03\).
2 — Evidence via total probability: \(P(\text{flag})=0.95\times0.005+0.03\times0.995=0.00475+0.02985=0.0346\).
3 — Bayes: \(P(F\mid\text{flag})=\dfrac{0.00475}{0.0346}\approx0.137\).
4 — Frequency check (per 100 000): 500 fraud → 475 flagged; 99 500 legit → 2 985 flagged; \(475/3460=13.7\,\%\). Most flags are false alarms because fraud is rare — the base rate dominates.

Sequential (Bayesian) updating

Today's posterior becomes tomorrow's prior. After a second independent positive ELISA: \[ P(D\mid++)=\frac{0.93\times0.12}{0.93\times0.12+0.01\times0.88}=\frac{0.1116}{0.1204}\approx0.93 . \] Equivalent one-shot form using the likelihood ratio \(LR=\dfrac{0.93}{0.01}=93\): posterior odds = prior odds × \(LR^k\). Prior odds \(=0.00148/0.99852\approx 1/675\); after two tests odds \(\approx 93^2/675\approx 12.8\), i.e. \(P\approx 0.93\). A third positive would push it to ≈ 0.999.
Apply it — a second, independent flag The same transaction is also flagged by a second, independent model with the same rates. Now what is the probability of fraud?
Show the step-by-step solution
1 — Odds form: after flag 1 the odds are \(\dfrac{0.137}{0.863}\approx0.159\).
2 — Likelihood ratio of a flag: \(LR=\dfrac{0.95}{0.03}\approx31.7\).
3 — Multiply: posterior odds \(=0.159\times31.7\approx5.04\) ⇒ \(P=\dfrac{5.04}{6.04}\approx0.83\).
Rule check: yesterday's posterior became today's prior; independence of the two models (given the truth) is what justified multiplying by \(LR\) once more. Two weak signals compound into a strong one.

Monty Hall and friends

Monty Hall You pick Door 1 (car with prob \(1/3\)). The host, who knows where the car is, always opens a goat door among the others. Your door still has \(1/3\); the remaining closed door therefore has \(2/3\). Always switch. Bayes check: \(P(\text{host opens 3}\mid\text{car at 1})=\tfrac12\), \(P(\text{host opens 3}\mid\text{car at 2})=1\), \(P(\text{host opens 3}\mid\text{car at 3})=0\). Posterior for Door 2: \(\dfrac{1\cdot\frac13}{\frac12\cdot\frac13+1\cdot\frac13}=\dfrac23\).
Challenge from the article — who really knew the answer? 60 % of students know the answer; those who know still pick wrong 15 % of the time; those who don't know guess right 25 % of the time. A student answered correctly — probability they knew? \[ \frac{0.85\times0.6}{0.85\times0.6+0.25\times0.4}=\frac{0.51}{0.61}\approx0.836 . \]
Apply it — Monty Hall with an ignorant host Same game, but this time the host does NOT know where the car is: he opens one of the other two doors at random, and it happens to reveal a goat. Should you still switch?
Show the step-by-step solution
1 — Write the likelihood of the observation under each hypothesis (you picked door 1, host opened door 3, goat visible):
car@1: host opens 3 with prob \(\tfrac12\), always goat → \(\tfrac12\). car@2: opens 3 with prob \(\tfrac12\), it is a goat → \(\tfrac12\). car@3: goat cannot be shown → 0.
2 — Bayes with equal priors: \(P(\text{car@1}\mid\text{obs})=\dfrac{1/2}{1/2+1/2}=\dfrac12\) — switching now gains nothing.
3 — Compare with the classic host (who always shows a goat deliberately): likelihoods were \(\tfrac12,1,0\) → switch wins \(\tfrac23\).
Moral: the information content of evidence depends on the process that produced it, not just on what you saw. This is the single most transferable Bayes lesson.

5. Random variables

A random variable \(X\) maps each outcome to a number, so we can do arithmetic with uncertainty. Coin: \(X=1\) for heads, \(0\) for tails. Two dice: \(Y=\) sum \(\in\{2,\dots,12\}\), not equally likely.

  • Discrete — countable values (die faces, number of defects, clicks). Described by a PMF.
  • Continuous — any value in an interval (rainfall, height, lifetime). Described by a PDF; probability of any single exact value is 0.

PMF, PDF, CDF

PMF (discrete): \(p(x)=P(X=x)\), with \(\sum_x p(x)=1\).
PDF (continuous): \(f(x)\ge0\), \(\int_{-\infty}^{\infty}f(x)\,dx=1\), and \[ P(a\le X\le b)=\int_a^b f(x)\,dx . \] Formally \(f(x)=\lim_{\Delta\to0}\dfrac{P(x\le X\le x+\Delta)}{\Delta}\) — a density, not a probability; \(f(x)\) can exceed 1.
CDF (both): \(F(x)=P(X\le x)\), non-decreasing from 0 to 1; \(P(a<X\le b)=F(b)-F(a)\); for continuous \(X\), \(f=F'\).
Trap "A fly lives between 4 and 6 days. Probability it dies at exactly 5 days?" For a continuous lifetime, \(P(X=5)=\int_5^5 f=0\). Only intervals have positive probability (e.g. \(P(4.9\le X\le5.1)\)).
Apply it — an unnormalised density A random variable has density \(f(x)=c\,x^2\) on \([0,2]\) (0 elsewhere). Find \(c\), \(P(X>1)\), and the median.
Show the step-by-step solution
1 — Normalisation axiom: \(\int_0^2 c\,x^2dx=c\cdot\tfrac{8}{3}=1\Rightarrow c=\tfrac38\).
2 — Build the CDF: \(F(x)=\int_0^x \tfrac38t^2dt=\dfrac{x^3}{8}\) on \([0,2]\).
3 — Use it: \(P(X>1)=1-F(1)=1-\tfrac18=\tfrac78\).
4 — Median solves \(F(m)=\tfrac12\): \(m^3=4\Rightarrow m=4^{1/3}\approx1.587\).
Rule check: the density rises like \(x^2\), so most mass sits near 2 — a median of 1.59 (well above the midpoint 1) is consistent.

Expectation and variance

\[ E[X]=\sum_x x\,p(x)\quad\text{or}\quad\int x f(x)\,dx, \qquad \mathrm{Var}(X)=E[(X-\mu)^2]=E[X^2]-\mu^2,\qquad \sigma=\sqrt{\mathrm{Var}(X)} \] Linearity (always, even if dependent): \(E[aX+bY]=aE[X]+bE[Y]\).
For independent \(X,Y\): \(\mathrm{Var}(X+Y)=\mathrm{Var}(X)+\mathrm{Var}(Y)\); in general \(\mathrm{Var}(aX)=a^2\mathrm{Var}(X)\).
Example — insurance policy Premium $210; payout $240 000 with probability \(1-0.999592=0.000408\). \[ E[\text{profit}]=210-240000\times0.000408=210-97.92\approx\$112 . \]
Example — lottery ticket Two digits (0–9, repeats allowed) + one letter. \(P(\text{grand})=\dfrac1{100\cdot26}=\dfrac1{2600}\); \(P(\text{letter only})=\dfrac1{26}\cdot\dfrac{99}{100}\). Cost $5. \[ E=\frac{10405}{2600}+100\cdot\frac{99}{2600}-5=4.002+3.808-5\approx\$2.81 . \] (A rare positive-expectation lottery — check the sign carefully.)
Example — expected wins at roulette \(P(\text{red})=18/38\). In 5 games \(E[\text{wins}]=5\times18/38=2.368\) — linearity of expectation, no binomial table needed.
Apply it — a risky project decision A project succeeds with probability 0.3, paying $500k; otherwise it loses $100k. Compute the expected profit and the standard deviation. Should a team that can only afford one attempt take it?
Show the step-by-step solution
1 — Expectation: \(E[X]=0.3(500)+0.7(-100)=150-70=\$80\text{k}\).
2 — Variance shortcut: \(E[X^2]=0.3(500^2)+0.7(100^2)=75\,000+7\,000=82\,000\); \(\mathrm{Var}=82\,000-80^2=75\,600\) ⇒ SD \(\approx\$275\text{k}\).
3 — Interpret: positive expectation but the SD dwarfs the mean — a single attempt loses money 70 % of the time. Expected value is a long-run average; for one-shot decisions you must also look at the distribution (here: can you survive the −$100k branch?).

6. Key distributions

Bernoulli and binomial

Bernoulli(\(p\)): one trial, \(X\in\{0,1\}\), \(E[X]=p\), \(\mathrm{Var}=p(1-p)\).
Binomial(\(n,p\)): number of successes in \(n\) independent Bernoulli trials. \[ P(X=k)=\binom{n}{k}p^k(1-p)^{n-k},\qquad E[X]=np,\qquad \mathrm{Var}(X)=np(1-p). \] Shape: symmetric when \(p=0.5\); skewed otherwise; approaches a normal curve as \(n\) grows (rule of thumb \(np\ge10\) and \(n(1-p)\ge10\)).
Worked examples
  • Football series (\(n=5,p=0.75\)): \(P(0)=0.001,\ P(1)=0.015,\ P(2)=0.088,\ P(3)=0.264,\ P(4)=0.395,\ P(5)=0.237\). Win the best-of-5 (≥3 wins): \(0.264+0.395+0.237=0.896\).
  • No red flowers in 5 crosses, \(p=0.25\): \(0.75^5=0.237\).
  • Win all 5 roulette games: \((18/38)^5=0.0238\).
  • 2 egg sandwiches of 3, \(p=0.7\): \(\binom32(0.7)^2(0.3)=0.441\).
  • Exactly 2 boys of 3, \(p=0.51\): \(3(0.51)^2(0.49)=0.382\).
  • 4 of 6 recover, \(p_{\text{recover}}=0.25\): \(\binom64(0.25)^4(0.75)^2=15\times0.003906\times0.5625=0.0330\).
  • 20 MCQs, 4 options: \(P(X=7)=0.112\); \(P(X\le7)=0.898\).
  • 50 heads in 100 tosses: \(\binom{100}{50}/2^{100}\approx0.0796\).
Example — "which is most likely?" At least one 6 in 6 rolls: \(1-(5/6)^6=0.665\). At least two 6s in 12 rolls: \(1-(5/6)^{12}-12(1/6)(5/6)^{11}=0.619\). At least three 6s in 18 rolls: \(0.597\). Same expected count (1, 2, 3) but the spread shrinks relative to the mean, so "at least the mean" gets slightly less likely. The first is most likely.
Apply it — drone passes over a damaged field Each drone pass detects existing hail damage with probability 0.8, passes independent. With 3 passes: (a) P(detected at least once), (b) P(detected in exactly 2 passes), (c) expected number of detecting passes.
Show the step-by-step solution
1 — Model: detections \(\sim\) Binomial\((n=3,p=0.8)\).
2 — (a) complement: \(1-(0.2)^3=0.992\).
3 — (b) binomial PMF: \(\binom32(0.8)^2(0.2)=3\times0.64\times0.2=0.384\).
4 — (c) mean: \(np=2.4\).
Rule check: the three answers used three different tools (complement, PMF, expectation) on one model — recognising the model first is what makes the rest mechanical.

Geometric and Poisson

Geometric(\(p\)) — number of trials until the first success: \(P(X=k)=(1-p)^{k-1}p\), \(E[X]=1/p\). Memoryless.
Poisson(\(\lambda\)) — count of events in a fixed interval when events arrive independently at rate \(\lambda\): \[ P(X=k)=\frac{e^{-\lambda}\lambda^k}{k!},\qquad E[X]=\mathrm{Var}(X)=\lambda . \] Approximates Binomial(\(n,p\)) when \(n\) large, \(p\) small, \(\lambda=np\).
Apply it — flaky test & weekly errors (a) A flaky CI failure reproduces on any run with probability 0.1. Expected runs to reproduce it, and P(more than 20 runs needed)? (b) A service throws errors at 0.5/day. P(at least one error next week)?
Show the step-by-step solution
1 — (a) Geometric(0.1): \(E=1/p=10\) runs; \(P(X>20)=(0.9)^{20}\approx0.122\) — a 12 % chance the bug hides past 20 runs even though the mean is 10; geometric tails are long.
2 — (b) Poisson over a window: weekly count \(\sim\) Poisson\((\lambda=0.5\times7=3.5)\); \(P(\ge1)=1-e^{-3.5}\approx0.970\).
Rule check: geometric answers "how long until the first success", Poisson answers "how many events in a window" — pick by the question's shape, not by habit.

Uniform and exponential (continuous)

Uniform(\(a,b\)): \(f(x)=\dfrac1{b-a}\) on \([a,b]\); \(P(c\le X\le d)=\dfrac{d-c}{b-a}\); \(E=\dfrac{a+b}2\); \(\mathrm{Var}=\dfrac{(b-a)^2}{12}\).
Exponential(\(\lambda\)): \(f(x)=\lambda e^{-\lambda x},\ x\ge0\); \(F(x)=1-e^{-\lambda x}\); \(E=1/\lambda\); memoryless. Models waiting times between Poisson events.
Example — exponential CDF \(f(x)=\tfrac18e^{-x/8}\) (\(\lambda=1/8\), mean 8). \[ P(X\le6)=1-e^{-6/8}=1-0.4724=0.5276 . \] Insect lifetime uniform on 0–16 days: \(P(5\le X\le6)=\int_5^6\tfrac1{16}dx=1/16\).
Apply it — battery lifetimes and bus stops (a) A battery\'s lifetime is exponential with mean 5 years. P(it lasts beyond 8 years)? Given it has already survived 3 years, P(it reaches 8)? (b) Buses arrive every 15 minutes and you arrive at a uniformly random time. Expected wait and P(wait < 5 min)?
Show the step-by-step solution
1 — (a) exponential survival: \(\lambda=1/5\); \(P(X>8)=e^{-8/5}=e^{-1.6}\approx0.202\).
2 — Memorylessness: \(P(X>8\mid X>3)=P(X>5)=e^{-1}\approx0.368\) — the 3 years already served are irrelevant.
3 — (b) uniform wait on [0, 15]: \(E=7.5\) min; \(P(W<5)=5/15=1/3\).
Contrast: the uniform wait has a hard ceiling (15 min); the exponential has no ceiling and no memory — two very different "waiting" models.

Normal distribution, CLT, z-scores

\[ f(x)=\frac1{\sigma\sqrt{2\pi}}\,e^{-\frac{(x-\mu)^2}{2\sigma^2}},\qquad X\sim N(\mu,\sigma^2) \] Symmetric about \(\mu\); mean = median = mode; larger \(\sigma\) ⇒ flatter and wider. Total area 1.
Empirical rule: \(\mu\pm1\sigma\) ≈ 68 %, \(\mu\pm2\sigma\) ≈ 95 %, \(\mu\pm3\sigma\) ≈ 99.7 %. So mean→+1σ ≈ 34 %, +1σ→+2σ ≈ 13.5 %, beyond +2σ ≈ 2.5 %.
z-score: \(z=\dfrac{x-\mu}{\sigma}\) (how many SDs from the mean); \(x=\mu+z\sigma\). Look up \(\Phi(z)=P(Z\le z)\) in a table or scipy.stats.norm.cdf.
Worked examples
  • Scores \(N(18,6^2)\): \(P(18\le X\le24)=P(0\le Z\le1)\approx34\%\).
  • Cholesterol \(N(150,15^2)\), value 172: \(z=22/15=1.47\), \(\Phi(1.47)=0.929\) ⇒ 93 % below, 7 % above.
  • Exam \(N(67,13.7^2)\): \(P(X\ge80)=1-\Phi(0.949)=0.171\).
  • IQ \(N(100,15^2)\): \(P(X>120)=1-\Phi(1.333)=0.091\).
  • Screen size 9.5 cm with \(\mu=9.99939,\ \sigma=0.04878\): \(z=-10.24\) — an extreme outlier.
  • Heights \(N(55,6^2)\): 95 % lie in \(55\pm12=[43,67]\) (not 37–73, which is ±3σ); 65 in (\(z=+1.67\)) is exactly as unusual as 45 in (\(z=-1.67\)); symmetric ⇒ equal numbers above and below 55. Hence "none of these".
Central limit theorem For i.i.d. \(X_i\) with mean \(\mu\) and variance \(\sigma^2\), the sample mean \(\bar X_n\) is approximately \(N\!\left(\mu,\ \sigma^2/n\right)\) for large \(n\), whatever the population's shape. The standard error \(\sigma/\sqrt n\) shrinks with \(\sqrt n\). This is why sample means (e.g. cholesterol averages of 50 people) pile up symmetrically around the population mean, and why the normal distribution is everywhere in statistics.
Apply it — crop yields, single plot vs field average Plot yields are \(N(3.2,\,0.5^2)\) t/ha. (a) P(a single plot yields under 2.5)? (b) For a field of 25 independent plots, P(the field average is under 3.0)?
Show the step-by-step solution
1 — (a) z-score: \(z=\dfrac{2.5-3.2}{0.5}=-1.4\); \(\Phi(-1.4)\approx0.081\) — about 8 % of plots.
2 — (b) CLT for the mean: \(\bar X\sim N\big(3.2,\,(0.5/\sqrt{25})^2\big)=N(3.2,\,0.1^2)\).
3 — z-score again: \(z=\dfrac{3.0-3.2}{0.1}=-2\); \(\Phi(-2)\approx0.023\).
Interpret: a single low plot is common (8 %), a low field average is rare (2.3 %) — averaging shrinks the spread by \(\sqrt n\). Mixing up the SD of one observation with the SE of a mean is the most common normal-distribution error in interviews.

Apply it — 10 heads in 12 flips, both ways A coin lands heads 10 times in 12 flips. Analyse it as a frequentist and as a Bayesian.
Show the step-by-step solution
1 — Frequentist: MLE \(\hat p=10/12\approx0.83\). Test \(H_0\!: p=0.5\): \(P(X\ge10)=\big[\binom{12}{10}+\binom{12}{11}+\binom{12}{12}\big]/2^{12}=79/4096\approx0.019\); two-sided p ≈ 0.039 — reject at 5 %.
2 — Bayesian: flat prior Beta(1,1) + data → posterior Beta(11, 3); posterior mean \(=\dfrac{11}{14}\approx0.786\); \(P(p>0.5\mid\text{data})\approx0.99\).
3 — Compare: both point the same way, but the numbers answer different questions — "how surprising is the data under fairness?" vs "what do I now believe about \(p\)?" With only 12 flips the Bayesian estimate is pulled toward the prior (0.786 < 0.833).

8. Classic traps (where marks are lost)

  1. Disjoint ≠ independent. Disjoint: \(P(A\cap B)=0\). Independent: \(P(A\cap B)=P(A)P(B)\).
  2. Base-rate neglect. A 99 %-accurate test for a 0.1 % disease still gives mostly false positives. Always multiply by the prior.
  3. Confusing \(P(A\mid B)\) with \(P(B\mid A)\) (the "prosecutor's fallacy"). Bayes is the bridge.
  4. Gambler's fallacy. Independent trials have no memory.
  5. Continuous variables: \(P(X=x)=0\); PDF values are densities and can exceed 1.
  6. Sampling without replacement changes probabilities (19/59, not 1/3; 3/6 · 2/5).
  7. "At least one" → compute \(1-P(\text{none})\).
  8. Order matters or not? Permutations vs combinations; for ordered draws the sample space is ordered pairs (boy–girl paradox).
  9. Empirical rule limits: 68/95/99.7 are for ±1/±2/±3σ, not other multiples.
  10. Monty Hall: the host's knowledge makes the door opening informative. Switch.
  11. Expected value sign and units: subtract the cost; keep track of whose perspective (insurer vs customer).
  12. \(P(A)\) must be in \([0,1]\) and \(P(A\cup B)\le1\) — a quick sanity check on any answer.

Part II — Advanced probability

Everything below goes beyond the mock exam. Part I is what a data-science interviewer expects you to know cold; Part II is what separates a good answer from a great one — and what quant-style questions (like the "coin flips → balls → bins" problem) actually test. Each section has the same ICAP ladder: read, explore, self-check, build your own, then spar with the tutor.

How to attack a multi-step probability problem
  1. Name the random variables and the stages of the process (what is random first, what depends on it).
  2. Condition on the first stage: write \(P(\text{event})=\sum_k P(\text{event}\mid K=k)\,P(K=k)\) or \(E[X]=E\big[E[X\mid K]\big]\).
  3. For "none / all / at least one" events use complement + inclusion–exclusion.
  4. For expectations of counts use indicator variables and linearity — never enumerate.
  5. Sum the series (geometric series are the usual ones), then sanity-check with small cases (k = 1, 2) and with bounds (is it in [0,1]? does it move the right way when a parameter changes?).

A1. Inclusion–exclusion as a tool

For events \(A_1,\dots,A_n\): \[ P\Big(\bigcup_{i} A_i\Big)=\sum_i P(A_i)-\sum_{i
Example — balls into bins (the core of the quant question) \(k\) balls placed independently and uniformly into \(m\) bins. \(P(A_i)=(1-\tfrac1m)^k\), \(P(A_i\cap A_j)=(1-\tfrac2m)^k\), … \[ P(\text{no bin empty})=\sum_{j=0}^{m}(-1)^j\binom{m}{j}\Big(1-\frac{j}{m}\Big)^{k} . \] For \(m=3\): \(1-3\big(\tfrac23\big)^k+3\big(\tfrac13\big)^k\). Check \(k=3\): \(1-\tfrac89+\tfrac19=\tfrac29=\tfrac{3!}{27}\) ✓ (the 6 permutations out of 27 placements). \(k=4\): \(1-\tfrac{48}{81}+\tfrac{3}{81}=\tfrac{36}{81}=\tfrac49\).
Example — derangements \(n\) people draw names at random; \(P(\text{nobody draws themselves})=\sum_{j=0}^{n}\frac{(-1)^j}{j!}\to e^{-1}\approx0.368\). Already at \(n=4\) it is \(0.375\). Interview follow-up: expected number of people who draw themselves = 1 for every \(n\) (indicators, see A3).
Apply it — reviewers and bins (a) Five reviewers are randomly assigned one paper each (their own papers are among the five). P(nobody reviews their own paper)? (b) Six balls are dropped uniformly into 3 bins. P(no bin empty)?
Show the step-by-step solution
1 — (a) derangement via inclusion–exclusion: \(\sum_{j=0}^{5}\frac{(-1)^j}{j!}=1-1+\tfrac12-\tfrac16+\tfrac1{24}-\tfrac1{120}=\tfrac{44}{120}\approx0.367\) — already near \(e^{-1}\).
2 — (b) the bins formula: \(1-3\big(\tfrac23\big)^6+3\big(\tfrac13\big)^6=1-\tfrac{192}{729}+\tfrac{3}{729}=\tfrac{540}{729}\approx0.741\).
Rule check: in both, the events being excluded ("reviewer \(i\) gets own paper", "bin \(i\) empty") overlap, so the alternating sum corrects the double counting that a naive \(\sum P(A_i)\) commits.

A2. Conditioning on a random first stage

Law of total probability (countable partition) \(\;P(E)=\sum_{k} P(E\mid K=k)\,P(K=k)\).
Law of total expectation (tower rule) \(\;E[X]=E\big[E[X\mid K]\big]\), and \(\mathrm{Var}(X)=E[\mathrm{Var}(X\mid K)]+\mathrm{Var}(E[X\mid K])\).
Wald's identity — sum of a random number \(N\) of i.i.d. terms: \(E[X_1+\dots+X_N]=E[N]\,E[X]\) (when \(N\) does not peek at the future).
Worked — the quant problem, fully Flip a fair coin until the first head; first head on flip \(K\) gives \(K\) balls, placed uniformly into 3 bins. \(P(\text{no bin empty})\)?
Stage 1: \(K\sim\text{Geometric}(\tfrac12)\): \(P(K=k)=2^{-k}\), \(k\ge1\).
Stage 2 (A1): \(P(\text{none empty}\mid K=k)=1-3(2/3)^k+3(1/3)^k\).
Combine: \[ \sum_{k\ge1}2^{-k}\Big[1-3\big(\tfrac23\big)^k+3\big(\tfrac13\big)^k\Big] =\sum_k\big(\tfrac12\big)^k-3\sum_k\big(\tfrac13\big)^k+3\sum_k\big(\tfrac16\big)^k = 1-3\cdot\tfrac12+3\cdot\tfrac15=\tfrac1{10}. \] (Geometric series: \(\sum_{k\ge1}r^k=\frac{r}{1-r}\).) Sanity: \(k\le2\) contributes 0, \(k=3\) contributes \(\tfrac18\cdot\tfrac29\approx0.028\), and the tail adds up to 0.1 — plausible.
Worked — random number of summands A store gets \(N\sim\text{Poisson}(20)\) customers a day; each spends on average $35. Expected daily revenue \(=E[N]E[X]=\$700\). Variance needs the tower rule: \(\mathrm{Var}=E[N]\mathrm{Var}(X)+\mathrm{Var}(N)E[X]^2\).
Apply it — die, then coins Roll a fair die; if it shows \(k\), flip \(k\) fair coins. Probability of getting no heads at all?
Show the step-by-step solution
1 — Condition on the first stage: \(P(\text{no heads}\mid K=k)=(1/2)^k\).
2 — Law of total probability: \(P=\sum_{k=1}^{6}\tfrac16\big(\tfrac12\big)^k=\tfrac16\Big(1-\tfrac1{64}\Big)=\tfrac16\cdot\tfrac{63}{64}=\tfrac{21}{128}\approx0.164\).
3 — Bonus (tower rule): expected number of heads \(=E[K]\cdot\tfrac12=3.5\times0.5=1.75\).
Sanity: the answer must sit between \((1/2)^6\approx0.016\) and \((1/2)^1=0.5\) — it does, closer to the small-\(k\) cases because they dominate the "no heads" event.

A3. Expectation tricks: indicators, first-step analysis, memorylessness

Indicators. For a count \(X=\sum_i \mathbf 1_{A_i}\): \(E[X]=\sum_i P(A_i)\) — works even when the \(A_i\) are dependent.
Tail-sum formula. For non-negative integer \(X\): \(E[X]=\sum_{k\ge1}P(X\ge k)\).
First-step analysis. Condition on the first trial and write an equation for the unknown expectation.
Memorylessness. Geometric and exponential: \(P(X>s+t\mid X>s)=P(X>t)\). The past does not shorten the wait.
Worked examples
  • Coupon collector. Rolls needed to see all 6 faces: once \(i\) faces are seen the next new face arrives in Geometric\((\frac{6-i}{6})\) time, so \(E=\sum_{i=0}^{5}\frac{6}{6-i}=6H_6=14.7\). General: \(nH_n\approx n\ln n\).
  • Expected maximum of two dice. \(E[\max]=\sum_{k=1}^{6}P(\max\ge k)=\sum_{k=1}^{6}\big[1-\big(\tfrac{k-1}{6}\big)^2\big]=6-\tfrac{55}{36}=\tfrac{161}{36}\approx4.47\).
  • Expected flips until HH vs HT. Let \(E\) = flips to get HH. First-step: \(E=1+\tfrac12E+\tfrac12\big(1+\tfrac12E+\tfrac12\cdot0\big)\Rightarrow E=6\). For HT the answer is 4 — a classic "why are they different?" follow-up (after a T you are not reset for HT, but you are for HH).
  • Fixed points of a random permutation. \(E=\sum_i P(\text{person } i \text{ gets own hat})=n\cdot\tfrac1n=1\).
  • Expected number of distinct birthdays among 30 people. \(365\big[1-(364/365)^{30}\big]\approx28.8\).
Apply it — counting with indicators (a) 20 people: expected number of pairs sharing a birthday? (b) 10 balls thrown uniformly into 5 bins: expected number of empty bins?
Show the step-by-step solution
1 — (a) one indicator per pair: \(E=\binom{20}{2}\cdot\dfrac1{365}=\dfrac{190}{365}\approx0.52\) — about half a pair on average, matching the ~50 % chance of at least one match at \(n=23\).
2 — (b) one indicator per bin: \(P(\text{bin } i \text{ empty})=(4/5)^{10}\approx0.107\), so \(E=5\times0.107\approx0.54\).
Rule check: the pair events and the bin events are dependent, and linearity did not care. Whenever a question says "expected number of …", reach for indicators before anything else.

Apply it — correlation of a sum with its part Roll two fair dice, \(X\) and \(Y\), and let \(S=X+Y\). Find \(\mathrm{Cov}(X,S)\) and \(\rho(X,S)\).
Show the step-by-step solution
1 — Bilinearity: \(\mathrm{Cov}(X,S)=\mathrm{Cov}(X,X)+\mathrm{Cov}(X,Y)=\mathrm{Var}(X)+0=\tfrac{35}{12}\approx2.92\).
2 — Variance of the sum (independence): \(\mathrm{Var}(S)=2\times\tfrac{35}{12}\).
3 — Correlation: \(\rho=\dfrac{\mathrm{Var}(X)}{\sqrt{\mathrm{Var}(X)}\sqrt{2\mathrm{Var}(X)}}=\dfrac1{\sqrt2}\approx0.707\).
Interpret: a total is correlated \(1/\sqrt2\) with each of its two equal parts — the same arithmetic explains why a portfolio co-moves with each holding, and why a model ensemble correlates with its members.

A5. Transformations and order statistics

CDF method. For \(Y=g(X)\) compute \(F_Y(y)=P(g(X)\le y)\) then differentiate. For monotone \(g\): \(f_Y(y)=f_X(g^{-1}(y))\,\big|\tfrac{d}{dy}g^{-1}(y)\big|\).
Inverse-CDF sampling. If \(U\sim\text{Uniform}(0,1)\) then \(F^{-1}(U)\sim F\); e.g. \(-\ln(U)/\lambda\sim\text{Exp}(\lambda)\).
Max / min of i.i.d. \(P(\max\le x)=F(x)^n\), \(P(\min> x)=(1-F(x))^n\).
Worked examples
  • \(n\) i.i.d. Uniform(0,1): \(E[\max]=\frac{n}{n+1}\), \(E[\min]=\frac1{n+1}\). The \(k\)-th smallest is Beta\((k,n+1-k)\).
  • Independent \(X_i\sim\text{Exp}(\lambda_i)\): \(\min\sim\text{Exp}(\sum\lambda_i)\) and \(P(X_i\text{ is the minimum})=\lambda_i/\sum_j\lambda_j\) (competing risks; also how "which server answers first" questions are solved).
  • \(Z\sim N(0,1)\): \(Z^2\sim\chi^2_1\); sum of \(n\) squared standard normals is \(\chi^2_n\) — the basis of chi-square tests.
Apply it — sensor fleet Three independent sensors each have Exp(1/10 yr) lifetimes. (a) Distribution and mean of the time to the first failure? (b) P(all three survive 5 years)?
Show the step-by-step solution
1 — (a) min of exponentials: rates add: first failure \(\sim\text{Exp}(3/10)\), mean \(10/3\approx3.3\) years — three sensors fail three times as fast as one.
2 — (b) independence product: \(P=\big(e^{-5/10}\big)^3=e^{-1.5}\approx0.223\) — the same number as \(P(\text{Exp}(3/10)>5)\), confirming (a).
3 — Bonus: P(sensor 2 is the first to fail) \(=\dfrac{\lambda_2}{\lambda_1+\lambda_2+\lambda_3}=\dfrac13\) by symmetry.

A6. Poisson process

Events arriving "at random" at rate \(\lambda\): counts in any window of length \(t\) are Poisson\((\lambda t)\); gaps between events are i.i.d. Exp\((\lambda)\); counts in disjoint windows are independent.
Thinning: keeping each event independently with probability \(p\) gives a Poisson process of rate \(p\lambda\). Superposition: merging independent processes adds the rates.
Poisson approximation: Binomial\((n,p)\approx\) Poisson\((np)\) for large \(n\), small \(p\) — rare-event counts (defects, fraud, hail strikes per field).
Worked examples
  • Support tickets at 3/hour. \(P(\text{none in 20 min})=e^{-1}=0.368\); \(P(\ge2\text{ in an hour})=1-e^{-3}(1+3)=0.801\).
  • Of those tickets 10 % are urgent ⇒ urgent tickets are Poisson at 0.3/hour; expected wait for the next urgent one is \(1/0.3\approx3.3\) h, regardless of how long you have already waited.
  • 1000 fields, each with a 0.2 % chance of hail damage: number damaged ≈ Poisson(2): \(P(0)=0.135\), \(P(\ge3)=0.323\).
Apply it — request spikes and thinning A web service receives 120 requests/min. (a) P(a given second gets more than 2 requests)? (b) 5 % of requests are API calls — what process do the API calls follow, and what is the expected gap between them?
Show the step-by-step solution
1 — (a) restate the rate for the window: 120/min = 2/sec, so the per-second count is Poisson(2).
2 — Complement over 0, 1, 2: \(P(\ge3)=1-e^{-2}(1+2+2)=1-5e^{-2}\approx0.323\).
3 — (b) thinning: independent 5 % selection of a Poisson process is again Poisson, rate \(0.05\times120=6\)/min; gaps are Exp(6/min), expected gap 10 s.
Rule check: converting the rate to the window you are asked about (step 1) is where most mistakes happen.

A7. Markov chains

A sequence \(X_0,X_1,\dots\) where the next state depends only on the current one: \(P(X_{n+1}=j\mid X_n=i)=P_{ij}\). Rows of the transition matrix \(P\) sum to 1. \(n\)-step probabilities are \(P^n\). A stationary distribution \(\pi\) satisfies \(\pi P=\pi\) and, for an irreducible aperiodic chain, is the long-run fraction of time in each state.
Absorption / first-step analysis: to find \(h_i=P(\text{absorbed in } A\mid X_0=i)\) solve \(h_i=\sum_j P_{ij}h_j\) with \(h=1\) on \(A\) and \(0\) on the other absorbing set.
Worked examples
  • Gambler's ruin (fair coin, bet 1 each round, start with \(i\), stop at 0 or \(N\)): \(P(\text{reach }N)=i/N\). With win probability \(p\ne\tfrac12\), \(r=(1-p)/p\): \(P=\dfrac{1-r^i}{1-r^N}\). Expected duration (fair) \(=i(N-i)\).
  • Weather chain \(P=\begin{pmatrix}0.8&0.2\\0.4&0.6\end{pmatrix}\) (sunny, rainy): \(\pi=(\tfrac23,\tfrac13)\) — solve \(0.2\pi_S=0.4\pi_R\), \(\pi_S+\pi_R=1\).
  • PageRank is the stationary distribution of a random surfer; hidden Markov models and MCMC sampling are the same machinery.
Apply it — churn steady state Each month 10 % of active users churn; each month 2 % of churned users reactivate. In the long run, what fraction of users is active?
Show the step-by-step solution
1 — Model as a 2-state Markov chain with \(P(\text{A}\to\text{C})=0.1\), \(P(\text{C}\to\text{A})=0.02\).
2 — Stationarity balances the flows: \(\pi_A\times0.1=\pi_C\times0.02\Rightarrow\pi_C=5\pi_A\).
3 — Normalise: \(\pi_A=\dfrac16\approx16.7\,\%\) active, \(83.3\,\%\) churned.
Interpret: the long-run split depends only on the ratio of the two rates — halving churn or doubling reactivation moves the steady state identically. This balance-the-flows shortcut solves any 2-state chain instantly.

A8. Inequalities, LLN, CLT — how sure can you be?

Markov: \(X\ge0\Rightarrow P(X\ge a)\le E[X]/a\).   Chebyshev: \(P(|X-\mu|\ge k\sigma)\le1/k^2\).   Chernoff/Hoeffding (bounded i.i.d.): \(P(|\bar X-\mu|\ge t)\le2e^{-2nt^2/(b-a)^2}\).
Law of large numbers: \(\bar X_n\to\mu\). CLT: \(\sqrt n(\bar X_n-\mu)/\sigma\to N(0,1)\); the error of a sample mean shrinks like \(1/\sqrt n\) — to halve it you need 4× the data.
Delta method: \(g(\bar X_n)\approx N\big(g(\mu),\,g'(\mu)^2\sigma^2/n\big)\).
Worked examples
  • Estimate a proportion to ±2 % with 95 % confidence: \(n=(1.96\cdot0.5/0.02)^2\approx2401\) (worst case \(p=0.5\)). For ±1 %: 9604.
  • A metric has mean 50, SD 10. Chebyshev: at most \(1/9\approx11\%\) of values lie outside \([20,80]\) whatever the distribution; if normal the true figure is 0.27 %.
  • Simulation accuracy: a Monte Carlo estimate of a probability \(p\) from \(n\) runs has SE \(\sqrt{p(1-p)/n}\) — 10 000 runs give about ±1 %.
Apply it — latency guarantees Response latency has mean 200 ms and SD 50 ms, distribution unknown. (a) Bound P(latency outside [50, 350] ms). (b) If latency were normal, what would that probability be? (c) How many samples to estimate the mean within ±10 ms at 95 % confidence?
Show the step-by-step solution
1 — (a) Chebyshev (no distributional assumption): 150 ms \(=3\sigma\), so \(P\le1/3^2=1/9\approx11\,\%\).
2 — (b) normal: \(2\Phi(-3)\approx0.27\,\%\) — Chebyshev is loose but unconditional.
3 — (c) CLT sample size: \(n=\Big(\dfrac{1.96\times50}{10}\Big)^2\approx96\).
Interpret: use Chebyshev when you must defend a claim with no assumptions (SLAs, adversarial reviews); use the normal numbers when the CLT or data justifies them.

A9. From probability to inference (what DS interviews actually ask)

Likelihood & MLE. \(L(\theta)=\prod_i f(x_i\mid\theta)\); maximise \(\log L\). Bernoulli: \(\hat p=k/n\). Normal: \(\hat\mu=\bar x\), \(\hat\sigma^2=\frac1n\sum(x_i-\bar x)^2\) (biased; divide by \(n-1\) for unbiased). Logistic regression = MLE of a Bernoulli model; least squares = MLE under Gaussian noise.
Confidence interval for a proportion: \(\hat p\pm z_{\alpha/2}\sqrt{\hat p(1-\hat p)/n}\); for a mean: \(\bar x\pm t_{n-1}\,s/\sqrt n\). Meaning: the procedure captures the truth 95 % of the time — not "95 % probability the truth is in this interval" (that is the Bayesian credible interval).
Hypothesis test & p-value. \(p=P(\text{data at least this extreme}\mid H_0)\). It is not \(P(H_0\mid\text{data})\) and not the probability the result is due to chance. Type I error \(\alpha\) (false alarm), Type II \(\beta\) (miss), power \(=1-\beta\).
A/B test sample size (two proportions, per group): \(n\approx\dfrac{\big(z_{\alpha/2}\sqrt{2\bar p\bar q}+z_{\beta}\sqrt{p_1q_1+p_2q_2}\big)^2}{(p_1-p_2)^2}\); rule of thumb for means: \(n\approx16\sigma^2/\delta^2\) at \(\alpha=0.05\), power 0.8.
Multiple comparisons. Testing 20 metrics at \(\alpha=0.05\) gives \(1-0.95^{20}=64\%\) chance of at least one false positive; Bonferroni uses \(\alpha/m\); Benjamini–Hochberg controls the false-discovery rate.
Probability inside ML models
  • Precision is Bayes' theorem. With recall (sensitivity) \(r\), false-positive rate \(f\) and prevalence \(\pi\): \(\text{precision}=\dfrac{r\pi}{r\pi+f(1-\pi)}\). Recall 90 %, FPR 5 %, prevalence 2 % ⇒ precision \(=0.018/(0.018+0.049)=27\%\). Class imbalance is base-rate neglect in disguise — the same arithmetic as the ELISA example.
  • ROC-AUC \(=P(\text{score of a random positive}>\text{score of a random negative})\). Precision–recall curves are the right view when positives are rare (hail-damaged fields, fraud).
  • Log-loss \(=-\frac1n\sum[y\log\hat p+(1-y)\log(1-\hat p)]\) is the negative log-likelihood of a Bernoulli model; calibration means \(\hat p=0.7\) is right about 70 % of the time (reliability diagram).
  • Entropy \(H=-\sum p\log p\), KL divergence \(D(P\|Q)=\sum p\log\frac pq\ge0\), cross-entropy \(=H(P)+D(P\|Q)\) — why "cross-entropy loss" is just MLE.
  • Naive Bayes assumes features independent given the class; Bayesian updating with a Beta prior: Beta\((a,b)\) + \(k\) successes in \(n\) trials ⇒ Beta\((a+k,\,b+n-k)\) — the basis of Bayesian A/B tests and Thompson sampling.
Apply it — sizing a conversion A/B test Baseline conversion is 5 %; you care about a lift to 5.5 %. (a) Sample size per arm at \(\alpha=0.05\), power 80 %? (b) A hail-damage classifier has recall 85 % and FPR 8 % at 5 % prevalence — precision?
Show the step-by-step solution
1 — (a) plug into the two-proportion formula with \(\bar p=0.0525\): \(n=\dfrac{\big(1.96\sqrt{2(0.0525)(0.9475)}+0.8416\sqrt{0.05(0.95)+0.055(0.945)}\big)^2}{0.005^2}\approx31\,000\) per arm.
2 — Interpret: detecting a 0.5-point lift on a 5 % base needs ~62k users total — small lifts on small bases are expensive; this is why teams test bigger changes or use variance-reduction (CUPED).
3 — (b) precision is Bayes: \(\dfrac{0.85\times0.05}{0.85\times0.05+0.08\times0.95}=\dfrac{0.0425}{0.1185}\approx36\,\%\).
Rule check: both are the same discipline — quantify the base rate before promising performance.

A10. Simulation and the bootstrap

When the algebra is ugly, simulate. Monte Carlo: draw many samples, count. Bootstrap: resample your data with replacement many times, recompute the statistic, and read the spread as its sampling distribution (percentile CI = 2.5th–97.5th percentile of the bootstrap estimates). Permutation test: shuffle labels to get the null distribution of a test statistic. Always fix a seed for reproducibility and report the Monte Carlo standard error. 
import numpy as np
rng = np.random.default_rng(42)

# The quant problem by simulation: flip until first head, put K balls in 3 bins
def trial():
    k = rng.geometric(0.5)                  # first head on flip k
    bins = rng.integers(0, 3, size=k)       # uniform bins
    return len(set(bins)) == 3
N = 200_000
p_hat = np.mean([trial() for _ in range(N)])
print(p_hat, "±", np.sqrt(p_hat*(1-p_hat)/N))   # ≈ 0.100 ± 0.0007

# Coupon collector, expected rolls to see all 6 faces
def rolls_to_collect(n=6):
    seen, t = set(), 0
    while len(seen) < n:
        seen.add(rng.integers(n)); t += 1
    return t
print(np.mean([rolls_to_collect() for _ in range(20_000)]))   # ≈ 14.7

# Bootstrap 95% CI for a mean
x = rng.exponential(8, size=60)
boots = [rng.choice(x, size=len(x), replace=True).mean() for _ in range(5000)]
print(np.percentile(boots, [2.5, 97.5]))

# Gambler's ruin, fair, start 3, target 10
def ruin(i=3, N=10):
    while 0 < i < N: i += rng.choice([-1, 1])
    return i == N
print(np.mean([ruin() for _ in range(20_000)]))   # ≈ 0.30

# Two-proportion A/B sample size per group
from scipy.stats import norm
def n_per_group(p1, p2, alpha=0.05, power=0.8):
    za, zb = norm.ppf(1-alpha/2), norm.ppf(power)
    pbar = (p1+p2)/2
    return ((za*np.sqrt(2*pbar*(1-pbar)) + zb*np.sqrt(p1*(1-p1)+p2*(1-p2)))**2) / (p1-p2)**2
print(round(n_per_group(0.10, 0.12)))   # ≈ 3800 per group
